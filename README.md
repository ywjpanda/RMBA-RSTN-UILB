# Robust Deadlock Avoidance for Dependent-Task Offloading in Remote-Sensing Satellite-Terrestrial Networks with an Unreliable Link and Buffer Constraints

**Authors:** Wenji Yang, Yikang Yang, Chao Fang, and Yanxiang Feng.

## Experiments

This repository provides programs, inputs, results, and supplementary materials for experiments on the robust modified banker's algorithm (RMBA). Experiments cover state certification and reachability, task completion under link disruption and recovery, scalability and buffer heterogeneity, and the trade-off between permissiveness and certification cost.
